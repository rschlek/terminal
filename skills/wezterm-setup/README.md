# wezterm-setup

- Maintainer: the terminal plugin maintainers
- Submitted: 2026-10-02

Installs WezTerm if it is missing, reconciles a minimal managed block into the
user's WezTerm config without clobbering it, and proves that a uniquely classed
WezTerm GUI can be started, addressed by `wezterm cli`, and closed - the engine
the sibling `shared-pane` skill needs.

## Prerequisites

A desktop session for the verification step. Installing may need admin rights;
on Linux there is a no-admin AppImage route. It ships one asset, no scripts.
